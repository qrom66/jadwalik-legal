# Jadwalik — legal & support pages

Public static pages for the **Jadwalik · جدولك** iOS app:

- [Support](https://qrom66.github.io/jadwalik-legal/support.html)
- [Privacy Policy](https://qrom66.github.io/jadwalik-legal/privacy-policy.html)
- [Terms of Service](https://qrom66.github.io/jadwalik-legal/terms.html)

The privacy policy and terms are generated from the app's own localisations
(`lib/l10n/app_{en,ar}.arb` in the private app repository) via
`tool/generate_legal_pages.py`, so the hosted pages cannot drift from what the
app displays. The support page is generated by `tool/generate_support_page.py`.

This repository contains **only** these published pages. The application source
is private.
